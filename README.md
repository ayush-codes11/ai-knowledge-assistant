# FastAPI Task Manager API

A simple backend CRUD API built using FastAPI, PostgreSQL, and Docker.

## Features
- Create, Read, Update, Delete tasks
- PostgreSQL database integration
- Dockerized database setup
- Swagger UI for testing endpoints

## Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker

## API Testing

http://127.0.0.1:8000/docs

Project built for learning backend development and REST APIs.
